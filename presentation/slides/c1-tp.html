TP 01

Installer le cluster

3 h 30 sur la journée · guide d'installation

tp-01-installation

Vous allez

  • préparer les 3 nœuds : swap, modules, sysctl, containerd
  • kubeadm init, Calico, join, tests réseau
  • arrêter le scheduler : les nouveaux pods restent Pending
  • labelliser, drainer puis rendre un nœud
  • retirer un worker du cluster, puis le réintégrer

C'est réussi quand

3 nœuds Ready, dont le worker réintégré

un pod joint un service nginx par son nom

HTTP 200 sur le NodePort des 3 nœuds

Le TP occupe le reste de la journée : préparation des nœuds avant le déjeuner ; kubeadm init, Calico, join, tests réseau et le control plane sans scheduler jusqu'à 15h00 ; gestion des nœuds après la pause. Sans scheduler : déplacer /etc/kubernetes/manifests/kube-scheduler.yaml hors du dossier, constater qu'un nouveau pod reste Pending, puis le remettre. Retirer un worker : kubectl drain, kubectl delete node, kubeadm reset sur le worker, kubeadm token create --print-join-command sur controlplane, puis kubeadm join. Pendant les temps d'attente (apt, images), poser les questions de l'énoncé : swap, br_netfilter, driver cgroup, apt-mark hold. En fin de TP, faire un snapshot des 3 VM. Correction : solutions/01-installation/, dans la branche du TP.

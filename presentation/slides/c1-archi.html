Le réseau entre les pods de tous les nœuds est fourni par le CNI : chez nous, Calico.

Tout passe par l'API server : kubectl, le scheduler, le kubelet. Seul l'API server parle à etcd. Le kubelet est l'agent de chaque nœud : il demande à containerd de lancer les conteneurs. kube-proxy programme les règles qui font fonctionner les Services. Sur un cluster kubeadm, les composants du control plane sont eux-mêmes des pods (static pods, /etc/kubernetes/manifests).

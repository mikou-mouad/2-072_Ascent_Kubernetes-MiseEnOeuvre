Docker

L'outil du poste de travail : construire, lancer, docker compose. C'est ce qu'utilise FestiPass sur sa VM.

containerd

Le runtime qui lance les conteneurs. Kubernetes lui parle directement (CRI), sans Docker. Même format d'image (OCI) : une image Docker y tourne telle quelle.

Faire le lien avec le Dockerfile de app/back : chaque instruction crée une couche en lecture seule, partagée entre conteneurs. Ce qu'un conteneur écrit va dans sa couche à lui, perdue quand on le supprime : c'est pour ça que les billets disparaîtront au TP 00, et au chapitre 6. Docker n'est plus le runtime de Kubernetes depuis la 1.24 (dockershim retiré), mais les images restent les mêmes.

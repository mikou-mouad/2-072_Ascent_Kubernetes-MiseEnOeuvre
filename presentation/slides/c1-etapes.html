# 4. sur controlplane
sudo kubeadm init --pod-network-cidr=192.168.0.0/16 --apiserver-advertise-address=10.10.0.10
# 5. le réseau des pods (Calico, via son opérateur)
kubectl create -f $BASE/operator-crds.yaml -f $BASE/tigera-operator.yaml
kubectl create -f $BASE/custom-resources.yaml
# 6. sur worker1 et worker2 (commande affichée à la fin de init)
sudo kubeadm join 10.10.0.10:6443 --token <token> --discovery-token-ca-cert-hash sha256:<hash>

Étapes détaillées dans guide-installation-cluster.md (sections 2 à 7). Pourquoi couper le swap, charger br_netfilter, aligner le driver cgroup : poser ces questions pendant les temps d'attente du TP. kubeadm init crée les static pods dans /etc/kubernetes/manifests et les certificats dans /etc/kubernetes/pki. Calico : utiliser create et non apply, les CRD sont trop volumineuses. Commande join perdue : kubeadm token create --print-join-command.

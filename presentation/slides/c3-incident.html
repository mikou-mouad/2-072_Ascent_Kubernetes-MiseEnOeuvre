« Le mot de passe de la base est sur GitHub »

Mardi

Un festivalier curieux écrit au festival : le dépôt de FestiPass est public, et le mot de passe de PostgreSQL y est en clair, dans docker-compose.yml et dans les manifests. embruns-2026, lisible par tout Internet.

« Et pour changer la limite de pass par commande, il faut vraiment reconstruire l'image ? » — Léa

Deux problèmes dans cet incident : un secret commité, et une configuration (PASS_MAX, nom du festival, annonce) mêlée au code ou à l'image. Demander : où rangez-vous vos mots de passe aujourd'hui ? Rappel : un secret poussé sur Git doit être changé, le supprimer du dépôt ne suffit pas.

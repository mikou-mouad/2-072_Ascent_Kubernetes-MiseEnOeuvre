Chapitre 2 · Le concept

YAML en cinq minutes

# une map : clé, deux-points, espace, valeur
nom: festipass
version: "1.0"          # chaîne : guillemets
replicas: 2             # nombre
# une map dans une map : on indente (espaces !)
metadata:
  name: back
  labels:
    app: back
# une liste : un tiret par élément
containers:
  - name: back          # liste de maps
    image: festipass-back:1.0
---                     # nouveau document

LES PIÈGES CLASSIQUES

Tabulation

Interdite. Uniquement des espaces, toujours le même nombre.

clé:valeur

Sans espace après les deux-points, ce n'est pas une map.

Un espace de trop

Le champ change de parent… sans erreur.

yes, on, 1.10

Lus comme booléen ou nombre : mettez des guillemets.

Faire le lien avec docker-compose.yml, que Yanis connaît : c'est déjà du YAML. Un manifest Kubernetes n'est que des maps et des listes imbriquées. --- sépare plusieurs objets dans un même fichier. Piège réel : version: 1.10 devient le nombre 1.1. Le TP 02 commence par réparer un fichier qui contient tous ces pièges.

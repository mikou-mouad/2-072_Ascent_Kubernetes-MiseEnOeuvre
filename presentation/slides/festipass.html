les billets vendus

Trois jours de concerts sur la plage de Saint-Malo, en juillet. Tout se joue à l'ouverture des ventes, vendredi 10h00, juste après l'annonce de la tête d'affiche. Chaque billet est signé par le back (PBKDF2) : c'est ce calcul qui consomme du CPU quand tout le monde achète en même temps. Le code est dans app/ du dépôt : docker compose up -d dans app/ montre l'application telle qu'elle tourne sur la VM.

Le dépôt des TP

Une branche par TP, chacune part de la précédente

tp-00

tp-01

tp-02

tp-03

…

tp-09

solution-finale

Branche tp-NN = l'application au début du TP NN, son énoncé (tp/NN-*/) et sa correction (solutions/NN-*/).

La correction ne dévoile rien du TP suivant.

Bloqué ? On consulte la correction, ou on repart de la branche du TP suivant.

# une fois, sur le control plane
git clone https://github.com/
  mikou-mouad/2-072_Ascent_Kubernetes-MiseEnOeuvre.git
  ~/festipass
cd ~/festipass && git checkout tp-00-conteneurs

# au début de chaque TP suivant
cd ~/festipass && git fetch
git stash -u
git checkout tp-03-configuration

Montrer le dépôt sur GitHub : app/ (le code de FestiPass), tp/ (les énoncés), solutions/NN-*/ (la correction de chaque TP : fichiers corrigés et réponses aux questions). git stash -u met de côté votre travail, y compris les fichiers non suivis : rien n'est perdu. La correction est volontairement accessible : chacun avance à son rythme.
